# Design System

## Purpose

Define the visual design language and UI standards for the IRDM Enterprise Website.

---

## Scope

Applies to

- Website
- CMS
- Admin Portal
- Django Templates
- HTMX
- Tailwind CSS
- Reusable Components

---

## Design Philosophy

- Figma First
- Pixel Perfect
- Component-Based
- Consistent
- Minimal
- Modern
- Professional
- Content-Centric
- Responsive
- Accessible

---

## Layout Principles

- Desktop First
- Mobile Responsive
- Consistent Grid
- Clear Visual Hierarchy
- Predictable Navigation
- White Space First

---

## Color System

Use semantic colors.

- Primary
- Secondary
- Accent
- Neutral
- Success
- Warning
- Error

Rules

- Colors are managed by Tailwind configuration.
- Never hardcode color values.
- Keep color usage consistent.

---

## Typography

- Consistent font family
- Consistent font size scale
- Consistent font weight
- Clear heading hierarchy
- Comfortable line height

Rules

- Use typography scale.
- Never use arbitrary font sizes.

---

## Spacing

- Consistent spacing scale
- Consistent padding
- Consistent margin
- Consistent section spacing

Rules

- Use Tailwind spacing utilities.
- Never use arbitrary spacing values.

---

## Border Radius

- Consistent radius
- Rounded cards
- Rounded buttons
- Rounded inputs

---

## Shadow

- Consistent elevation
- Minimal shadow
- Clean appearance

---

## Icons

- Heroicons
- Consistent icon size
- Consistent icon spacing

---

## Images

- Responsive
- Lazy Loading
- Optimized
- Consistent Aspect Ratio

---

## Components

Every component must be

- Reusable
- Independent
- Configurable
- Accessible
- Responsive

---

## Responsive Design

Support

- Mobile
- Tablet
- Laptop
- Desktop

Use Tailwind default breakpoints.

---

## Accessibility

- Semantic HTML
- Keyboard Navigation
- ARIA where required
- Visible Focus State
- Sufficient Color Contrast

---

## Animation

- Minimal
- Smooth
- Fast
- Purposeful

Avoid unnecessary animations.

---

## Tailwind Rules

- Utility First
- Component Reuse
- No Inline Style
- No Custom CSS unless necessary

---

## UI Consistency

Always

- Follow Figma.
- Reuse existing components.
- Keep layouts consistent.
- Keep spacing consistent.
- Keep typography consistent.
- Keep color usage consistent.

Never

- Duplicate UI.
- Hardcode styles.
- Mix different visual styles.
- Ignore responsive behavior.

---

## AI Notes

Always

- Generate pixel-perfect layouts.
- Follow the Design System.
- Reuse existing UI components.
- Use Tailwind CSS.
- Keep HTML semantic.

Never

- Invent new design patterns.
- Ignore Figma.
- Create duplicate components.
- Generate inconsistent layouts.

---

## Definition of Done

- Design philosophy approved.
- Layout principles approved.
- Color system approved.
- Typography approved.
- Responsive rules approved.
- Accessibility rules approved.
